## Lien du site trouve-ton-artisan

https://trouve-ton-artisan-frontend-ot4y.onrender.com/

1. Note sur la latence de chargement: Le site s'ouvre mais les images ne sont chargées qu'au bout d'une quinzaine de secondes environs. Une fois le site completement chargé, il fonctionne sans probleme. La réouverture du site une deuxieme fois, est beaucoup plus rapide.

2. Note sur l'envoi de messages dans le formulaire: L'envoi de message a été testées avec succes en changeant un email d'un artisan par mon propre email, il faudra donc avoir acces à au moins une adresse email d'un artisan pour pouvoir tester cela par le correcteur. A défaut, veuillez créer un nouvel email identique a un des emails fournis dans le projet.
